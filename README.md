## ⚙️ How to Update Business Details

### 1. Shop WhatsApp Number
Open `script.js` and find line 7:
```js
const SHOP_WHATSAPP = '923001234567'; // ← Replace with real number
```
Format: `92XXXXXXXXXX` (country code 92 + 10-digit number, no spaces or dashes)

### 2. Shop Address & Opening Hours
Search for `[ Address to be added` and `[ Opening hours` in `index.html` and replace with real details.

### 3. Owner Photograph
Replace `owner.jpg` with the actual photo (keep the same filename).

### 4. Shop Name
The shop name **"Suleman Chicken House"** appears in:
- `index.html` — page title, nav logo, hero, footer, about, contact
- Use Ctrl+F to find and replace all instances if needed.

### 5. Google Maps
Find the `map-placeholder` div in `index.html` and replace it with a Google Maps embed iframe.
